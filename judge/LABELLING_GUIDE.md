# Labelling guide

Each image is a 3D reconstruction rendered from a new viewpoint.
For each image, answer one question:

**Does the image contain visible reconstruction artefacts?**

Answer **yes** if you can clearly see any of these:
- **floaters**: semi-transparent blobs, haze or specks floating in empty space
- **specks**: the image looks grainy or dotted, like a point cloud
- **holes**: parts of an object or surface that are missing
- **broken geometry**: surfaces that look melted, streaked, torn, or doubled

Answer **no** if the image looks like a clean photo or rendering.

Ignore:
- mild overall softness or slight blur
- colour, brightness or lighting
- what the object is, or whether it looks nice
- the plain white background itself

Answer every image, yes or no. If unsure, pick the one that fits better.
Do not look at any other file while labelling.
